1 Label Size Selection

Select the correct label size based on the carton height:

A5 Standard
Height > 15 cm

Standard layout for most cartons.

Custom Wide
Height 10-15 cm

Wide layout for short cartons.

2 Carton Type Options

Choose how sizes are packed inside the carton:

SINGLE SIZE

Carton contains only one size.

RATIO (MIXED)

Carton contains multiple sizes.

(Displays size table with quantities)

  • Single: Enter just the size value (e.g., "XL").
  • Ratio: Up to 12 size slots available (7 pre-filled: XS to 3XL, plus 5 custom). Enter the size name and quantity for each.
  • A5 Layout: Sizes are displayed in 2 rows of 6 with a separator border between rows.
  • Custom Layout: All sizes are displayed in a single row.

5 Final Steps

Review Preview

Check all details on the live preview before exporting.

2

Export PDF

3

Print

Print on A4 paper with scale set to "Actual Size" or 100%.

6 Printing Specs

  • Stock: Pressure sensitive label paper
  • Weight: 60 GSM or higher
  • Finish: Matte or low gloss
  • Opacity: 75% minimum

7 Troubleshooting

  • Text cut off: Add a space between words to allow wrapping.
  • Corner box missing: "H" box only for Homeware.
  • Wrong label size: Verify carton height.
  • Preview issues: Exported PDF is correct even if mobile preview is off.
  • Size too small: Ensure "Actual Size" print scale.
